The data and codes are for the manuscript “Early warning signals to anticipate critical transitions in high-dimensional systems”.
Authors: Koushik Garain, Chao-Jui Chang, Jer-Horng Wu, Hsiao-Pei Lu, Arndt Telschow, Chun-Wei Chang, Chih-hao Hsieh.

1. To determine the appropriate embedding dimension and window size, run the script 'Demo_check_embedding_dim.R'. By default, it uses the Lake Zurich dataset, but it can be applied to all other datasets as well.

2. To reproduce the figures in the main manuscript, run the corresponding scripts. (The embedding dimension and window size used here are taken from 'Demo_check_embedding_dim.R'.)

3. Figures 3 and 4 each consist of three parts, with each part generating one panel (column) of the final figure.
