# MM-DEV

## Early Warning Signals to Anticipate Critical Transitions in High-Dimensional Systems

This repository contains the **code and data** associated with the manuscript:

**“Early warning signals to anticipate critical transitions in high-dimensional systems”**

### Authors

Koushik Garain, Chao-Jui Chang, Jer-Horng Wu, Hsiao-Pei Lu, Arndt Telschow, Chun-Wei Chang, and Chih-hao Hsieh


## Overview

Critical transitions can cause abrupt and potentially irreversible changes in complex dynamical systems. Detecting such transitions in advance is particularly challenging when the underlying system is high-dimensional and contains many interacting variables.

This repository provides the implementation and datasets used to evaluate **MM-DEV**, a multivariate extension of the Dynamical Eigenvalue (DEV) framework for detecting early-warning signals of critical transitions in high-dimensional systems.

The approach uses **empirical dynamic modeling (EDM)** and **S-map** to reconstruct local system dynamics directly from time-series observations. For high-dimensional systems, dimensionality reduction using **ISOMAP** is incorporated before estimating the local dynamical behavior.

The repository contains analyses of both model-generated and empirical/experimental systems, including:

* Lotka–Volterra ecological models
* High-dimensional Ricker model
* Lake Zurich plankton community
* Methane-producing bioreactor systems

These examples are used to investigate the performance of MM-DEV across different types of critical transitions and systems of varying dimensionality.

## Data

The repository contains four main groups of datasets.

### 1\. Ricker Model

High-dimensional Ricker-model time series simulated in **R**.

The model framework follows the approach described in:

Grziwotz et al. (2023), *Anticipating the occurrence and type of critical transitions*, Science Advances.

DOI: `10.1126/sciadv.abq4558`

### 2\. Lotka–Volterra Model

Multivariate ecological time series simulated in **MATLAB** using a Lotka–Volterra food-web framework.

The model construction follows the approach described in:

Lever et al. (2023), *Five fundamental ways in which complex food webs may spiral out of control*, Ecology Letters.

DOI: `10.1111/ele.14293`

### 3\. Lake Zurich

Long-term empirical plankton-community and environmental time series from **Lake Zurich, Switzerland**.

The dataset and its use are associated with:

Merz et al. (2023), *Disruption of ecological networks in lakes by climate change and nutrient fluctuations*, Nature Climate Change.

DOI: `10.1038/s41558-023-01615-6`

and

Medeiros et al. (2025), *Revealing unseen dynamical regimes of ecosystems from population time-series data*, Proceedings of the National Academy of Sciences.

DOI: `10.1073/pnas.2416637122`

### 4\. Bioreactor Data

Experimental data from methane-producing anaerobic bioreactor systems generated by members of the research team and collaborators.

The related experimental system is described in:

Chang et al. (2025), *Bioenergetically constrained dynamical microbial interactions govern the performance and stability of methane-producing bioreactors*, npj Biofilms and Microbiomes.

DOI: `10.1038/s41522-025-00668-z`

For complete information about individual files and data provenance, see [**Data/Data-README.md**](Data/Data-README.md).


## Software Requirements

The analyses are implemented primarily in **R**.

The scripts use the following R package:

```r
rEDM
```

Additional functions from standard/base R are also used.

### Important note on `rEDM`

Some of the MM-DEV calculations use S-map coefficient output and functions corresponding to **rEDM version 1.2.3**.

For exact reproduction of the analyses, users should therefore use a compatible version of `rEDM`.


## Running the Analysis

The repository is designed so that the scripts can be run from the **root directory of the repository**.

For example:

```text
MM-DEV/
```

should be used as the R working directory so that paths such as

```r
read.csv("Data/lake_zurich.csv")
```

correctly locate the datasets.

### Step 1 — Determine embedding dimension and window size

Run:

```r
Demo_check_embedding_dim.R
```

This script determines appropriate values of the **embedding dimension (`E`)** and **moving-window size** using S-map forecasting performance.

By default, the script uses the Lake Zurich dataset:

```text
Data/lake_zurich.csv
```

The same procedure can be applied to the other datasets by changing the input dataset.

The embedding dimension and window size obtained from this procedure are subsequently used in the corresponding MM-DEV analyses.

### Step 2 — Reproduce Figure 2

Run:

```r
Figure_2.R
```

This script contains the analyses of the model-generated datasets used in **Figure 2**, including the Lotka–Volterra and Ricker-model examples.

### Step 3 — Reproduce Figure 3

Figure 3 is divided into three components. Run:

```r
Figure_3_1.R
Figure_3_2.R
Figure_3_3.R
```

Each script generates the corresponding panel/column of Figure 3.

### Step 4 — Reproduce Figure 4

Similarly, Figure 4 is divided into three components. Run:

```r
Figure_4_1.R
Figure_4_2.R
Figure_4_3.R
```

Each script generates the corresponding panel/column of Figure 4.

### Step 5 — Reproduce Supplementary Figures

The supplementary analyses can be reproduced using:

```r
Figure_S_8_10_11.R
Figure_S_9.R
Figure_S_12.R
Figure_S_13.R
```

The script names indicate the corresponding supplementary figures.


## Data Provenance

The repository contains a combination of:

* model-generated simulated data,
* publicly available ecological observations, and
* experimental bioreactor data generated by members of the research team and collaborators.

The simulated Ricker and Lotka–Volterra datasets were generated for the present analyses following previously published modeling frameworks.

The Lake Zurich dataset is based on publicly available long-term ecological observations.

The bioreactor datasets originate from experimental work conducted by members of the research team.
